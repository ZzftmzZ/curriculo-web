# Portfólio - Cauê Mateus Gil

Este repositório contém o código fonte do meu portfólio profissional hospedado no GitHub Pages.

## Tecnologias Utilizadas

* HTML5 Semântico
* CSS3 (Custom Properties, Flexbox)
* Tema de Cores: [Catppuccin Mocha](https://github.com/catppuccin/catppuccin)
* Open Graph & JSON-LD para SEO avançado

## Estrutura de Arquivos

```text
/
├── index.html       # Página principal e única
├── css/
│   └── style.css    # Estilos do tema Catppuccin
├── js/              # (Opcional) Scripts futuros
└── assets/          # (Opcional) Imagens, ícones, etc.
```

## Como usar

1. Clone o repositório ou baixe o arquivo zip.
2. Edite o arquivo `index.html` e substitua `SEU-LINKEDIN-AQUI` pelo seu perfil real do LinkedIn.
3. Se quiser adicionar imagens (favicon, og-image), coloque-as na pasta `assets` e descomente as linhas `<link rel="icon"...>` e `<meta property="og:image"...>` no `index.html`.
4. Faça o push para o branch `main` do seu repositório `curriculo-web`.
5. Vá nas configurações do repositório no GitHub > Pages e ative a publicação a partir da branch `main`.
